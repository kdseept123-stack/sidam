# 강동구 행사 수집

강동구 관련 사이트를 돌면서 **주민 참여 행사**를 모아 정리하고,
인스타그램에 올릴 **사실 정보 블록**과 **포스터 이미지**를 뽑아주는 도구.

- 결과는 HTML 리포트 1개로 나오고 실행이 끝나면 브라우저에서 자동으로 열림
- 소개말·톤·해시태그·업로드는 직접 (이 도구는 정보 수집·정리까지만)

## 처음 한 번만 설정

1. **Python 설치** (이미 있으면 넘어감) — <https://www.python.org>
2. **Gemini API 키 발급 (무료)**
   - <https://aistudio.google.com/apikey> 접속 → 구글 로그인 → `Create API key`
   - 유료 결제 필요 없음
3. **키 넣기**
   - `config\.env.example` 파일을 복사해서 같은 폴더에 `config\.env` 로 저장
   - 파일을 열어 `GEMINI_API_KEY=` 뒤에 발급받은 키를 붙여넣고 저장

## 실행

`강동행사_체크.bat` 더블클릭. (또는 명령창에서 `python main.py`)

- 처음 실행 때 필요한 패키지와 브라우저 엔진을 자동으로 받음 (몇 분 걸릴 수 있음)
- 끝나면 `output\강동행사_YYYYMMDD\index.html` 이 브라우저에서 열림
- 포스터 이미지는 `output\강동행사_YYYYMMDD\posters\` 에 저장됨 → 인스타 올릴 때 여기서 선택

## 사이트 추가·삭제

`config\sources.txt` 를 메모장으로 열어서 편집:

- 한 줄에 URL 하나
- 맨 앞에 `#` 을 붙이면 잠시 꺼둘 수 있음
- 게시판 목록 주소든, 행사 글 하나 주소든, RSS 주소든 다 됨
- 저장하고 다시 실행하면 반영됨

기본으로 들어있는 소스: 강동구청 강동소식 · 강동문화재단 공연 · 서울문화포털 · 강동구 온라인 소식지

## 동작 방식

1. `sources.txt` 의 각 사이트에서 최근 글(기본 12개)을 가져옴
2. 각 글을 Gemini 에 보내 행사 정보를 추출·분류
   - `행사` / `애매`(주민설명회 등) / `행사아님`(채용·입찰·강동구 밖 행사 등)
   - 글 하나에 행사가 여러 개면 각각 분리
   - 원문에 유아·유모차·수유실·연령 관련 언급이 있으면 `👶` 정보로 추출 (없으면 생략, 추측 안 함)
3. **마감이 지나지 않은 행사**만 리포트에 실음 (지난 게 확실할 때만 제외)
4. 포스터 이미지 다운로드
5. HTML 리포트 생성 → 자동 열기
6. 안내한 행사는 `history.db` 에 기록 → **다음 실행부터는 리포트에서 제외** (한 번 알려준 행사는 다시 안 보여줌)
   - 처음부터 다시 보고 싶으면 `history.db` 파일을 지우고 실행

## 참고

- 컴퓨터가 꺼져 있으면 돌지 않음. 작업 시작할 때 직접 실행하는 방식.
- 관공서 사이트는 구조가 자주 바뀜. 특정 소스에서 수집이 안 되면 리포트 맨 아래 "소스별 수집 결과" 에 표시됨.
- LLM 사용량은 하루 1회 실행 기준 Gemini 무료 한도 안에 충분히 들어옴.
- 나중에 품질이 아쉬우면 `config\.env` 에서 `GEMINI_MODEL` 을 `gemini-3.5-flash` 등으로 바꿀 수 있음.
